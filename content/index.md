# 雑らて へようこそ

ここは **雑らて** — Obsidian で書いたノートを [Quartz](https://quartz.jzhao.xyz/) で公開するデジタルガーデンです。

このページは公開セットアップ確認用の**デモページ**です。実際に公開するノートはこれから手動で追加していきます。

## 使い方

1. Obsidian の vault で記事を書く
2. 公開したいノートを `content/` に置く（または frontmatter で管理）
3. `npx quartz sync` で push すると GitHub Actions が自動でビルド・デプロイ
